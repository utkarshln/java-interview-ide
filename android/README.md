# Android WebView — Java Interview IDE

Least manual: **PWA install** (0 build) → open https://utkarshln.github.io/java-interview-ide/ on Android Chrome → banner **Install** → app icon.

For Play Store APK:
1. Open `android/` in **Android Studio**
2. Sync Gradle
3. **Build → Generate Signed Bundle / APK → APK** → `app-release.apk`

Loads https://utkarshln.github.io/java-interview-ide/ with full Run (via https://java-interview-ide.onrender.com backend). No code change needed.
