# Java Interview IDE — by Utkarsh

Pink, zero-import Java IDE for interviews. Local JDK auto-detect, auto-comment pasted questions.

- **Local (full execution):** `node server.js` → http://localhost:5173 (requires JDK 17/21/25)
- **Static (free):** https://utkarshln.github.io/java-interview-ide/ (editing + tests UI, Run needs backend)
- **Full-stack free deploy:** Click **Deploy to Render** below (Docker with JDK) — free tier.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/utkarshln/java-interview-ide)

Or Railway: `railway up` in this folder.
